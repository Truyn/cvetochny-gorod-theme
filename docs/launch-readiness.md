# Предзапусковая проверка «Цветочного города»

Тема содержит встроенную страницу `Внешний вид → Готовность к запуску`.

Она проверяет без автоматического изменения настроек:

- HTTPS публичного адреса;
- постоянные ссылки;
- разрешение индексации;
- назначение политики конфиденциальности;
- страницы WooCommerce: каталог, корзина, оформление и личный кабинет;
- назначение условий продажи / оферты;
- наличие включённого способа оплаты;
- наличие включённого способа доставки;
- наличие SEO-плагина или использование безопасного fallback темы.

Дополнительно тема:

- закрывает от индексации поиск, 404, корзину, checkout, личный кабинет и избранное;
- исключает служебные WooCommerce-страницы из XML sitemap WordPress;
- выводит базовые description/Open Graph/Twitter метаданные только если SEO-плагин не обнаружен;
- убирает часть устаревшего head-вывода WordPress и публичный emoji payload.

## Перед запуском вручную

После зелёного технического чек-листа всё равно нужен живой тест: оформить заказ как покупатель, проверить доставку, оплату, письмо, данные заказа в админке и уведомление ВКонтакте. После этого проводится визуальный аудит страниц на компьютере и телефоне.

Юридические тексты не генерируются автоматически: для них нужны подтверждённые реквизиты продавца и фактические правила обработки персональных данных магазина.
